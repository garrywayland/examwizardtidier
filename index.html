Diagram sizes

Defaults are guessed from each image's native resolution relative to the others in this paper. Adjust anything that looks wrong, then close this panel — the preview updates live.

✏️ Click any text in the paper to edit it directly — Ctrl/Cmd+B bold, Ctrl/Cmd+I italic, Ctrl/Cmd+Z undo. Type ^2 (or ^{2n+1} / ^(2n+1) for multi-character powers) and it will auto-convert to a real superscript as soon as you type a space or punctuation after it. Click any image (diagram or equation) to type its LaTeX by hand — leave the box blank to put the original image back (need help writing it? try latexeditor.lagrida.com). Switching layout or re-uploading will discard edits.
